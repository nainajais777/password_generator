
# React Password Generator

A clean and responsive password generator built with **React.js**, **Tailwind CSS**, and **Vite**.

Customize password length, include numbers or special characters, and copy to clipboard instantly!

---
![App Screenshot](./public/prj_screenshot)

## Features

- Adjustable password length (6–100)
- Toggle inclusion of numbers and symbols
- Copy password to clipboard
- Responsive UI using Tailwind CSS
- Built using React + Vite
- React Hooks used:
  - `useState`
  - `useEffect`
  - `useRef`
  - `useCallback`

---

##  Concepts Used

- **`useRef`** – For accessing and selecting input field
- **`useCallback`** – For stable memoized functions
- **`useEffect`** – To trigger password generation on updates
- **Tailwind CSS** – For hover, layout, spacing, and color transitions
